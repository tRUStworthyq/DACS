# Тема входа DACS для Keycloak

Тема `dacs` находится в `infra/keycloak/themes/dacs`. Она рассчитана на Keycloak 26.6 из dev Compose и наследует тему `keycloak`. Вход и регистрация используют собственную обёртку `login/dacs/template.ftl`; остальные страницы, включая сброс пароля и обязательные действия, используют стандартные шаблоны Keycloak.

## Подключение

Из корня репозитория выполните:

```powershell
docker compose -f infra/docker-compose.dev.yml up -d --no-deps keycloak
```

Compose монтирует тему в `/opt/keycloak/themes/dacs` в режиме чтения. Ссылки «На главную» и логотип ведут на `DACS_HOME_URL` (по умолчанию `http://localhost:8765/`). Для другого окружения задайте внешний URL DACS через эту переменную.

1. Откройте административную консоль Keycloak.
2. Выберите realm **DACS** и откройте **Realm settings → Themes**.
3. В поле **Login theme** выберите **dacs** и сохраните.
4. Начните новый вход через приложение или через Gateway по `/oauth2/authorization/keycloak`.

Ссылка на регистрацию доступна при включённой самостоятельной регистрации. Восстановление пароля, «Запомнить меня» и согласие с условиями появляются в соответствии с настройками и потоком Keycloak. Форма регистрации выводит все поля, заданные профилем realm, и использует его правила проверки.

Левая панель основана на `AuthArtwork` и стилях из `dacs-frontend`. Шрифты и SVG загружаются из каталога темы. Лицензии включены рядом с ресурсами.
